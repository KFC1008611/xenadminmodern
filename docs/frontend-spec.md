# 前端界面规范

生效日期：2026-10-23。以用户确认的[桌面 HTML 样机](design/modern-desktop/index.html)为视觉基线。本文约束实际 React 前端；样机演示数据和模拟操作不进入产品。

## 连接恢复与主机信息（2026-11-05）

新增连接、已保存服务器和重连入口共用中文网络与证书错误说明，先说明故障，再给出检查步骤，并保留诊断错误码。提示不重复端点或原始套接字报文，避免将脱敏占位符作为原因展示；原始诊断仍按现有 IPC 规则脱敏。macOS 遇到主机/网络不可达或系统拒绝联网时，补充“系统设置 → 隐私与安全性 → 本地网络”的检查步骤，不直接认定权限是故障原因。证书信任链、过期、尚未生效及地址不匹配分别提示修复；只有明确自签名错误才提示确认可信后允许自签名证书。错误文字允许换行，弹窗保持内部滚动及操作可达，不增加配置项或自动重试。

侧栏未连接服务器在展开和折叠状态均提供可聚焦的重连按钮，资源读取异常详情也提供同一入口。网络故障、会话失效、自动恢复耗尽和手动断开后的记录可重连；进行中显示加载并禁止重复提交。连接页保留未保存的失败端点，已保存服务器沿用原卡片及密码恢复。手动断开在本次应用会话保留端点与主进程凭据，不自动重连；退出应用清除运行记录，持久服务器配置沿用原机制。

重连失败保留原服务器、具体原因及重试入口，需要更换密码时可直接输入；不把网络错误推断为密码错误。密码通过凭据脱敏的 IPC 发送，成功认证后用于同一连接；若关联已保存服务器，沿用系统加密存储更新密码。重连、断开及迟到响应受连接代次保护，不重发原资源操作。

主机列表显示 CPU 逻辑处理器数量、型号、插槽、运行中 VM 数量、系统版本和内存容量。详情补充主机名、管理地址、UUID、CPU 频率与系统构建。列表、详情、主机监控和仪表盘内存卡显示总容量、已用与可用容量，以 GiB 等二进制单位呈现；百分比图表保留。内存读取 XAPI 主机 RRD 数据源，KiB 转为字节；缺失、无效或读取失败时显示具体原因，不伪造零容量或推算成功值。

## 页面结构

- 桌面窗口采用侧栏、顶部上下文栏、滚动内容区。侧栏展开宽 232px，折叠宽 64px，保留资源池树和全局导航。窗口标题拖动区与 macOS 系统按钮区域保留。
- 顶栏高 56px，显示当前路径的面包屑；资源池状态、任务通知、刷新、断开和外观菜单持续可达。长名称截断，完整名称可通过 title 查看。面包屑不能扩大窗口宽度。
- XVA 导入、导出的校验和传输阶段分别显示实际百分比、已处理/总文件字节数、已用时间和平均速度。校验按实际归档文件大小计算，全部通过才显示 100%；上传按本地文件大小计算，下载仅在服务端提供真实 Content-Length 时显示百分比，否则显示已接收量与“总大小未知”。服务器处理直接显示 Task 进度，准备、配置核对和清理没有可计量进度时显示不定进度；不得用预估容量、固定阶段权重或计时模拟百分比。普通操作卡片获得数值进度时同时显示百分比文字。
- XVA 导入记录恢复或任务读取失败时，静态显示具体原因，不用持续滚动的进度条暗示仍在上传；弹窗中的同一原因只显示一次。恢复本地记录的提示不推断应用曾经重启。重连后沿用原任务，不能自动重新上传。
- 导入完成后的 VM、Task 和模板刷新跟随该次结果返回的当前原池连接，避免旧连接刷新错误；导出清理中断后继续核对原清理，完成后移除恢复时的待清理提示。导入/导出恢复提示均不推断应用曾重启。旧记录缺少原池身份时，取消失败须给出具体原因，不能误显示已经取消。
- 页面正文左右留白 24px，窄窗口 16px；最大宽 1600px。页面标题 20px/600，正文 14px，表格和表单 12–14px，辅助文字最低 11px。字体使用系统字体栈，数字用等宽数字。
- 支持 1024×768、1280×800、1440×900、1920×1080 桌面窗口。较窄窗口允许工具栏换行、卡片减少列数，表格在容器内横向滚动；页面本身不能横向溢出。无需设计移动端。

## 组件

- 面板圆角 10px，按钮/输入圆角 7px；边框 1px。页面面板平面化，仅菜单、弹窗、浮动任务面板使用阴影。去除装饰渐变、发光和无意义副标题。
- 文案以完成操作为目的。删除与标题重复的说明、重复的范围提示、空泛引导和常驻成功提示；不要为填满卡片补文字。保留对象名称、资源范围、数量、单位、状态、错误、禁用原因和实际操作后果。资源读取正常时不显示独立状态栏，首次读取和读取异常时才显示；后台更新已有数据不占用正文行，旧数据和失败提示继续保留。
- 禁用提示直接说明当前不可用的操作，例如「存储仓库分离与销毁暂不可用」。内部批次、审计编号、接口实现阶段保留在开发记录中，不出现在常规操作提示里；文案精简不改变操作的开放或禁用状态。
- 主要操作使用紫色实底和对比文字；普通操作用中性色，危险动作使用错误色。禁用状态保留禁用原因及现有权限、能力、对象状态保护。工具栏不能因操作按钮增多而挤出视口。
- 列表使用统一表头底色、细行分隔、悬停反馈。复选框始终对齐，名称与状态优先显示，单位写明。虚拟机行内保留启动、关闭或恢复快捷操作，其余操作放入带文字的「更多操作」菜单，保留全部禁用原因和确认流程。固定操作列用不透明面板底色；不得遮住可滚动数据。沿用既有搜索、筛选、完整批量目标清单及跨资源池限定。
- 虚拟机与模板统一列表在一页显示完整筛选结果，不设分页或行数截断。类型、名称、状态、IP 地址、资源池、主机、vCPU、内存均可点击表头排序；默认名称升序。普通点击表头切为单列排序，再次点击切换方向；Shift + 点击按点击顺序追加排序列，再次 Shift + 点击只切换该列方向。例如先点类型、再 Shift + 点名称，即类型升序、名称升序。多列时表头显示方向和优先级数字，主排序列提供 `aria-sort`，按钮提供可读的优先级、方向及键盘焦点。名称和 IP 等文本采用自然顺序，vCPU 和内存按实际数值排序；缺失、未上报及读取失败的值在对应分组内始终置后，全部排序列同值才按连接及对象引用稳定排序。排序在刷新和筛选时保留。“全选虚拟机”覆盖完整筛选结果；批量目标核对、隐藏选择提醒和操作保护沿用原规则。
- 合并 VM 与模板清单时，同一“连接＋XAPI 对象引用”只显示一行；当前 VM 记录优先于旧模板缓存。模板 provision 为 VM 时同步更新模板缓存。名称不是对象身份，不合并同名对象，也不合并不同连接下引用相同的对象。
- 统一列表默认只显示虚拟机和用户模板；系统自带模板在“显示类型”中勾选“系统模板”后显示。创建向导仍可选择系统模板。
- 表单使用一致的标签、输入背景、边框和紫色焦点提示；错误贴近字段。原生 checkbox/radio 使用主题强调色，保持可见尺寸。说明文字仅解释取值、后果或操作要求。
- 弹窗优先复用 `DesktopDialog`：保留焦点圈定、Escape、焦点返回和忙碌保护。长内容内部滚动，关键确认和错误可见；不借视觉改版改变操作确认、异步取消或结果未确认状态。
- 标签页使用紫色文字/底线或浅紫选中底，未选中项为次要文字。资源名称、容量、错误和接口标识允许换行，必要时提供局部滚动。
- 图表网格、坐标和提示浮层消费主题变量；曲线颜色保持同一指标的固定含义。无数据、采集失败、旧数据不能画成正常的零值。
- 外观菜单支持 Enter/Space、方向键、Home/End、Escape 和 Tab；点击外部关闭，关闭后保留合理焦点。所有可交互控件有可见焦点；遵循减少动态效果偏好。
- 层级必须让菜单可实际点击：内容内固定表格列为 10、读取状态栏为 20、独立操作菜单和任务浮层为 40、顶栏为 45、模态遮罩及内容为 50。顶部外观菜单位于顶栏的局部 50 层，不能被正文状态栏或任务浮层覆盖；弹窗遮罩使用主题背景的 80% 不透明度并保留上下文。验收须在任务浮层展开时点击主题选项并检查实际主题，不能仅检查菜单存在。

## 功能与文档对齐

本次只迁移视觉和主题偏好，不增加或删减 XAPI 操作。连接恢复、资源池路由、保存密码流程、权限、读取错误及旧数据提示、虚拟机状态保护、操作确认、任务历史与后台传输按现有实现和[桌面工作流](desktop-workflows.md)、[虚拟机复制](vm-copy.md)、[XVA 传输](xva-transfers.md)执行。

对象和操作语义沿用 [XAPI](https://xapi-project.github.io/xen-api/)、[Xen Orchestra](https://docs.xen-orchestra.com/manage-your-infrastructure/manage_infrastructure)、[XenCenter](https://docs.xenserver.com/en-us/xencenter/current-release/) 的资源池、主机、虚拟机、存储、网络分类。界面不得暗示尚未确认的服务器结果。

复制窗口在源当前光驱挂载 ISO 时阻止跨池复制，提示具体设备和手动弹出后重读预检的步骤；空光驱及同池复制按原能力执行。预检无可用方式时隐藏方式和存储选择，保留原因及重读入口。光驱保留关系和恢复规则见[复制规范](vm-copy.md)。

后续用户可见变更需同步本规范、实现及相关工作流文档。验收至少覆盖两种主题、连接页与工作区、主列表/详情/弹窗/任务浮层，以及上述桌面尺寸；主题测试须检查保存、启动恢复及菜单键盘行为。构建或本地浏览器检查不等于真实 XCP-ng 验收。

## 统一任务通知（2026-11-04）

连接页与工作区均在右上角保留铃铛图标，首次打开和重新进入应用时默认收起，有活动任务时显示提示点。点击展开同一个面板，集中显示普通操作、批量任务、XVA 导入/导出、VM/模板复制及所有资源池的服务器 Task。移除各角落的独立浮层及导入、导出专用顶栏按钮。新任务、完成、失败和取消均不自动展开；收起、切换页面或打开外观菜单不停止后台跟踪。任务详情页与操作窗口的上下文反馈继续保留。

面板固定在顶栏下方右侧，限制宽度与窗口内高度，列表内部滚动；长对象名、错误和路径可换行。支持键盘打开、Escape 收起并返回铃铛焦点、点击外部关闭。面板展开时外观菜单仍可操作；模态窗口继续优先于任务面板。

各类任务先显示进行中的记录，已完成、明确失败和已取消的记录收进默认折叠的「已结束（数量）」；展开后保留逐条删除入口。读取故障、原记录丢失和导出清理尚未完成的记录继续可见。历史折叠不卸载后台观察，不改变独立任务页的完整列表。

取消沿用各任务的能力和阶段保护，等待服务器终态才显示已取消。重复点击合并为同一请求；批量任务的“停止后续操作”不撤销已执行的动作。不支持中断的阶段显示具体原因。普通同步请求不能在客户端伪造取消，已创建的服务器异步 Task 可在服务器任务中请求取消。

已结束的执行记录可逐条删除，导出同时保留批量清理入口；活动任务和仍在清理的导出记录不能删除。删除只移除本地展示，不删除 VM、副本、文件、服务器 Task 或用于恢复及防重放的日志。复制、批量与服务器 Task 的删除标记保存在 `xenadmin-deleted-task-records`，轮询、列表刷新和应用重启不恢复已删除的终态卡片；同一批量任务在其他入口重试后，新的活动进度仍显示。普通操作在本次会话保留完成记录，直至用户删除，不再三秒自动移除。旧的独立面板展开状态不再恢复；不新增用户配置项。

批量重试成功受理后清除该任务的旧删除标记，新一轮最终结果继续保留在通知和历史页，直至再次删除；重试提交失败时保留原标记。历史页读取重试项期间禁用本行删除；若从通知删除了记录，迟到的读取响应不再打开确认框。重试提交期间，历史页和通知均禁用该任务的删除入口。

## 刷新与选择一致性（2026-11-04）

VM 详情顶部刷新同时重读当前磁盘或快照标签的数据；全局 VM 清单成功刷新后，当前详情及其设备清单随之重读。磁盘关系或电源状态改变时重读 VBD/VDI，不要求切换标签才能恢复磁盘按钮。刷新保留已打开的操作窗口，迟到的旧设备响应不能覆盖新读取结果；失败显示具体原因并可原地重读。

网络详情的主机接口跟随当前资源池主机、网络清单的成功刷新重新读取 IP 和链路状态；读取失败保留已有数据并显示错误。连接作用域改变后不接纳旧接口响应。

批量选择在确认前同步当前名称；连接断开、代次或资源池身份改变、VM 消失、引用对应的 UUID 改变或转为模板时，移除失效选择并显示数量及重新选择提示，保留其他目标。已经打开的确认窗口保持原目标和名称；名称或身份变化后禁用确认并要求取消后重新核对，不能自动替换已确认目标。提交中的目标继续按原任务处理。

磁盘激活、停用、分离和删除从点击或打开确认起至操作及状态回读结束保持互斥；冲突按钮禁用并显示处理中反馈。取消或处理结束后恢复可用状态，读取失败时禁止沿用旧磁盘数据操作。

全局 VM 页已筛选的资源池断开或移除后，选择与实际筛选同时回退为“全部资源池”；原连接恢复不自动抢回筛选。

## 模板删除（2026-11-02）

删除用户模板的窗口提供“同时删除所属硬盘”，默认不勾选，重新打开或切换模板后恢复默认。勾选后明确说明永久删除及保护范围：只清理模板独占、可写且归属明确的硬盘；共享盘、只读盘、快照盘、在途操作中的盘及光驱介质保留。系统模板继续禁止删除。

提交期间禁止关闭、修改选择和重复提交。服务器确认模板删除后再清理磁盘；部分磁盘保留或清理失败时保留窗口和具体引用，提示到存储中检查，禁止再次删除已删除的模板。清单刷新失败与删除结果分别展示；请求失败保留具体原因并要求刷新模板及存储清单后再操作，不直接重新提交。

## 常用表单与连接恢复（2026-11-02）

保存的服务器被 XAPI 明确拒绝登录时，连接页和“连接已保存服务器”窗口均直接提供密码输入，保留拒绝原因；新密码登录成功后沿用原服务器记录保存，不要求另建连接记录。网络或权限故障不解释为密码错误。

模板设置保存期间冻结字段、取消、Escape 和重复提交；正文内部滚动，底部保存按钮和具体错误保持可达。成功反馈以原模板身份和全部提交字段的读回为准。部分设置未保存时说明未完成字段，CPU 调整同时显示实际启动数和最大数；结果读取失败显示具体读取故障。上述两种情况保留窗口并禁止沿用旧表单提交，要求关闭后重新读取模板列表再编辑。已确认保存后的清单刷新失败单独提示；切换模板或管理连接后，旧请求不能关闭新窗口或回填新对象。

模板字段写入之间若管理连接身份变化，也按结果读取失败处理；即使前端尚未刷新连接状态，旧表单仍禁止再次提交。

告警规则阈值接受后端支持的数值，包括 83%、82.5% 及任意有效 B/s 值，不额外限制为 5% 或 1 MiB/s 的倍数。百分比范围为 0–100%，持续时间为 1–1440 分钟的整数。保存期间冻结字段和关闭入口，禁止重复提交。

## 磁盘创建与移动窗口（2026-11-02）

新建磁盘和移动磁盘的仓库选择均排除 `iso`、`udev` 及 `content_type=iso` 的仓库，移动时还排除原仓库。没有目标时显示具体空态并禁止提交；目标清单读取失败保留原因并提供原地重读，重读不清空新建磁盘的草稿。同一磁盘记录刷新不重置已选移动目标。

两个窗口均按对象和连接生命周期隔离读取与提交结果；切换对象或重新打开后，旧请求不得回填、刷新或关闭新窗口。提交只发送一次；连接变化后静态显示原请求结果的读取故障，保留关闭入口并禁止重发。移动请求报错后须关闭窗口、重新读取磁盘与存储清单再操作。

磁盘创建成功后，父列表同步或异步刷新失败单独显示，不能改为创建失败。已创建但附加未完成时保留磁盘引用；附加结果读取失败显示具体故障，两者均不能直接重建。错误与结果文字允许换行，正文内部滚动，底部按钮保持可达。没有新增配置项。

## 虚拟机批量管理（2026-11-05）

批量工具栏提供带文字的「启动」「正常关闭」「正常重启」「挂起」「从挂起恢复」「暂停」「继续运行」「创建快照」「删除」，支持换行，删除使用危险色。全部所选 VM 均满足电源状态、锁定、在途操作、管理员禁用和 XAPI 能力条件才开放操作；禁用原因指出具体 VM。清单读取失败、缺少完整身份或目标已有未结束批量任务时禁止提交。执行前主进程逐项重新读取能力和身份；互不重叠的任务可并行。迁移和强制关闭继续逐台操作。

点击 VM 行空白处选择单台，Ctrl／⌘ 点击行或名称增减选择；复选框直接增减选择。Shift 点击行、名称或复选框，按当前排序选择锚点至点击行之间的可见 VM，跳过模板，保留范围外和筛选外选择；锚点已不在当前筛选结果时只选择点击项。普通点击名称仍进入详情。选中行显示选中底色，全选框显示部分选中状态。全选覆盖完整筛选结果，提交期间锁定选择。

全部操作先显示冻结的 VM/资源池清单和实际后果；名称、身份或操作条件变化后禁止确认。批量删除仅允许已停止的 VM，确认窗口默认勾选“同时删除所属硬盘”，可取消以保留硬盘。单台 VM 删除同样默认勾选可安全删除的所属硬盘，重开窗口恢复默认；共享、只读、快照、在途和归属不明的磁盘保留，单台窗口显示原因。VM 和磁盘删除后分别读回确认；清理磁盘前再次核对身份和挂载关系。VM 已删除但清理失败时列出 VDI 引用，不计为完整成功，禁止直接重试该删除任务；单台窗口保留结果并禁止再次删除。清单刷新失败单独展示。没有新增用户配置项。

批量任务页显示全部活动任务和历史；类型旁显示实际 VM 名称及数量，每个活动任务可停止后续操作。任务表允许容器内横向滚动、右侧操作列固定且底色不透明；状态文字、时间和结果数字不按单个汉字断行。全部批量任务同时进入右上角任务通知，保留最终计数、逐项错误和完整任务页链接；新任务受理和任务结束均不自动展开通知。列表刷新失败或后台历史清理不丢掉已收到的结果；用户可删除已结束记录。批量界面不使用「结果未确认」状态；无法读取服务器执行结果时显示「读取结果失败」、具体故障及查看虚拟机状态和服务器任务记录的步骤，并单列「读取失败」数量，不计为成功或可直接重试的执行失败。历史强制关闭及迁移操作标明「历史」，不显示重试；支持操作的明确失败项需要重新读取、确认具体目标和后果后重试。

终态浮层按任务身份补读逐项详情；摘要补充时间字段不能清空已有结果。详情重读失败时保留已收到的逐项错误并显示具体原因，重读成功后更新；旧响应不能覆盖已开始的重试。

## 模板快速创建（2026-10-23）

用户模板菜单根据 `instant=true` 显示「快速创建 VM」或「启用快速创建」。启用只修改标记并刷新原资源池模板；快速创建的提示须明确会创建并启动。锁定、在途操作、电源状态及 XAPI 的 clone 能力共用主进程资格规则，禁用时显示具体原因。处理中防止重复提交；异步服务器任务在任务页查看。

读回确认 Running 才显示创建并启动成功。已经创建但启动未完成、已有未完成副本、结果未确认均使用警告，保留 VM/Task 引用；列表刷新失败单独提示。连接身份变化后不以旧结果刷新替换后的资源池。持久核对与模板准备要求见[模板快速创建](vm-quick-create.md)。


## 模板创建向导（2026-10-23）

向导使用主进程的模板磁盘计划，加载失败或模板切换时禁止用旧计划继续；读取失败提供原地重试。存储步骤与确认页显示实际硬盘数量、设备号、GiB 容量、只读状态和目标 SR，自定义模板的光驱不计入硬盘数。未知 XML 存储不得默认选择清单第一项。已有只读盘容量控件禁用。

安装方式按模板启动类型显示 ISO、PXE、安装源 URL 或不使用介质。URL 输入与实际安装仓库一致，网络安装无网卡时阻止继续；无可用网络的提示必须反映此约束。模板网卡保留的 MTU、QoS、锁定和地址限制在网络步骤、确认页可见，MAC 自动生成。确认页展示实际 CPU 每插槽核数。长 URL、磁盘清单、网卡地址和错误在桌面弹窗内部换行和滚动，底部操作保持可见。

## 逐页检查修正（2026-10-23）

创建 VM 的确认按钮固定在向导底部操作栏，摘要内部滚动；提交中、配置不完整和结果未确认的禁用规则与提示沿用原工作流。检查记录见[逐页 UI 检查](reviews/2026-10-23-page-audit/review.md)。


## VM 监控读取（2026-10-23）

VM 监控查询串行执行，自动刷新在本轮结束后等待 30 秒。切换时间范围合并为最新查询，连接身份或 VM 改变后不显示旧响应；页面卸载不再发送排队请求。读取失败保留当前对象已有数据，并显示具体原因，成功重读后清除错误。关闭自动刷新取消下一轮定时器，已有请求正常结束；查询等待期间保留刷新按钮的忙碌反馈。历史在后台恢复完成前保持读取中，恢复失败不能画成正常空历史或零值。实现边界见[桌面工作流](desktop-workflows.md)。

停机 VM 不依赖运行清单补齐历史；仅有本地旧样本时仍需按需读取归档。成功补读后，在当前连接身份和采集代次内复用；失败或空归档可重试，重连或重启采集后重新初始化。运行中的 VM 连续 30 秒没有观察到样本时间推进时，下一次详情查询重新读取归档，覆盖主机历史初始化失败、增量失败及重复旧样本的情况；该 VM 持续收到新样本时不重复下载。最近 60 秒的运行清单确认 VM 不在运行时继续复用停机历史；清单过期后恢复归档检查。

## 基础管理表单与反馈（2026-10-25）

虚拟网卡列表增加带说明的换网按钮；确认窗口列出目标网络并说明连接中断，保持桌面弹窗内部滚动。添加网卡发生读取故障时在表单内保留错误，冻结原网络和 MAC，操作按钮改为“重新读取创建结果”；该动作只核对原请求。统一进度卡片显示“状态读取失败”及具体故障，不显示“结果未确认”，不把读取故障计为操作成功或服务器明确执行失败。

## 操作记录与再次提交（2026-10-26）

导入向导与导入历史独立保存。上次操作已完成、失败或取消时，再次打开向导从选择文件开始，原结果保留在任务通知中的导入历史；移除当前已结束记录同时释放向导引用，重启后不得恢复已移除记录。受理响应尚未返回时继续防止重复提交；已受理的活动记录继续跟踪原操作，晚到进度不能覆盖已确认终态或新的草稿。

进度查询明确返回本地操作不存在时，任务卡片显示“本地导入/导出记录已不存在，已停止自动读取”，停止进度动画、自动轮询和活动计数，提供仅移除本地记录的入口；移除不取消服务器任务、不删除对象或文件，也不代表服务器失败。IPC 读取异常与本地记录不存在分别处理，短暂读取异常仍按原操作重试。

导出点击取消后立即显示正在请求取消，完成、失败或已取消一旦由原 Task 确认，不得被较晚的取消回复或旧进度改回活动状态。网卡确认删除后可以发起新的创建请求；旧请求保留“已删除”记录，旧请求 ID 不得重新创建网卡。原记录仍存在、读取权限不足或连接身份变化时，继续保留原请求保护。
