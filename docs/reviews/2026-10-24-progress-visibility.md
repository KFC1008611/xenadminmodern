| 操作或页面 | 原有显示与缺口 | 本轮处理 |
| --- | --- | --- |
| XVA 导入本地校验 | 上一轮已补百分比、字节数和耗时，尚无速度 | 补充按已检查字节数和本阶段耗时计算的平均速度 |

| XVA 下载 | 有数据量和整体耗时，但没有速度；缺少 Content-Length 时用虚拟容量估算百分比 | 补充本阶段耗时和平均速度；总长度未知时只显示已接收量、速度及“总大小未知”，取消预估百分比 |
| 导出下载后的本地校验 | 固定停在 99%，没有已检查字节、校验速度或耗时 | 接入完整校验器的实际字节位置与耗时，单独显示校验百分比和平均速度 |
| 通用操作卡片 | 获得数值进度时只有条形图，没有百分比文字 | 同时显示百分比文字及可访问的进度数值；无进度的同步操作保留执行中状态 |
| 磁盘扩容 | 服务器尚未报告进度时固定显示 0% | 未提供进度时显示不定进度，收到服务器数据后显示实际 Task 百分比 |
| VM/模板同池、跨池复制 | 已显示服务器 Task 进度，接口没有传输字节数 | 保留原 Task 观察流程，不按虚拟容量乘进度推算传输量或速度 |
| 任务页、批量管理 | 分别显示服务器 Task 进度、实际已处理项目数和结果分类 | 未发现已取得的传输速度被漏显示；保留现有数据来源 |
| ISO 仓库扫描、创建、迁移和补丁应用 | 当前同步工作流有执行中反馈，未向前端提供可计量的阶段分母或传输字节 | 保留执行中与结果反馈，不用计时模拟百分比；ISO 文件由用户放入共享目录，当前页面不执行文件上传 |

校验、上传和下载的平均速度均为本阶段实际已处理字节数除以本阶段已用时间，不是瞬时网络带宽，也不用于生成剩余时间。上传字节计数来自交给 HTTP 请求的本地文件流，不代表服务器磁盘已经持久写入相同数量的数据；最终结果仍以原 Task 和后置校验为准。

前端复用同一套传输进度显示。未知进度使用移动的活动标记，无数值百分比，并遵循减少动态效果偏好。阶段切换时更新文字与数据，服务器处理不继续显示已结束的上传速度。IPC 契约接收传输计数、阶段及校验数据，严格校验计数范围；仅用 -1 表示未知进度，不接受任意负数。
