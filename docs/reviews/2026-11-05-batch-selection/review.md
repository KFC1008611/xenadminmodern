# 批量操作与默认删盘验证（2026-11-05）

VM 列表支持行选择、Ctrl／⌘ 增减选择、Shift 按当前排序范围选择；范围跳过模板并保留其他及筛选外选择，全选框显示部分选中状态。macOS 将 Ctrl 点击发送为 contextmenu 的路径单独处理，普通点击名称继续进入详情，提交期间禁止选择变更。

批量操作新增暂停、继续运行、创建快照和删除，共 9 项。全部目标满足电源状态、锁定、在途操作、管理员保护和 XAPI allowed_operations 才启用，提示具体目标和禁用原因；提交前冻结清单，执行时重读身份与能力。正常关闭不升级为强制断电，迁移继续使用单台工作流。

单台和批量 VM 删除默认勾选所属硬盘，可取消以保留。只清理独占、可写、归属明确的普通硬盘；共享、只读、快照及在途磁盘保留。删除前后核对 VM、连接和 VDI 身份及挂载关系，读回确认删除。VM 已删除但磁盘未完成清理时保留引用，不显示完整成功，禁止直接重试 VM 删除；清单刷新失败单独反馈。未新增配置项。

语义参考 [XAPI VM](https://xapi-project.github.io/xen-api/classes/vm.html) 和 [XenCenter 删除 VM](https://docs.xenserver.com/en-us/xenserver/8/vms/delete.html)；默认勾选按本次用户要求实现。
