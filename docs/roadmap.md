# 后续工作

优先完善 VM、虚拟磁盘、网络、快照和模板的基础操作。当前实现以 [README](../README.md)、[桌面工作流](desktop-workflows.md) 和 [证据清单](../src/shared/evidence-manifest.ts) 为准，实机差距见 [验证记录](validation.md)。本页合并旧 B1–B8 工单的未完成方向，历史编号、测试数量和调查基线不作为当前实施依据。

| 方向 | 待完成范围 |
| --- | --- |
| 工具链与验证（B1） | 保持固定工具链、确定的测试集合、类型/lint/覆盖率检查；补足协议、IPC、真实 Electron、打包应用和 CI 平台证据 |
| 操作与身份（B2） | 统一主进程执行校验、资源池与对象 UUID、连接代次、确认意图、持久操作记录、Task 与后置状态；记录部分生效、结果未知和清理残留 |
| 连接恢复（B3） | 完整退出后的凭据恢复、主节点切换、部分权限、失联与重连、窗口重建，以及旧事件与旧指标隔离的实机验证 |
| VM 核心操作（B4） | 创建、模板、快照、计算配置、设备和单 VM 删除的完整对象归属、数据保留、失败清理与跨重启恢复；批量仅保留常规电源操作 |
| 数据传输与观测（B5） | XVA 大文件与恢复、真实控制台、RRD/Event/Task/Message、告警历史与外部通知的完整工作流 |
| 存储、网络与重定位（B6） | SR 分离/销毁、PBD 和 backend 能力、全池网络拓扑及管理接口保护；同池/跨池停机复制的实机矩阵与在线快照准备；跨池迁移、整机存储移动的完整映射与数据保留验收 |
| 主机与资源池治理（B7） | 维护/疏散、主机电源、主节点与成员变更、HA、补丁、RBAC 和外部认证的阶段状态、维护窗口及恢复 |
| 桌面与发布（B8） | 统一活动记录、异常入口、资源池工作区、密集表格、全局搜索/最近对象与键盘交互；最终完成各平台签名、安装、升级和发布验收 |

实施时按当前源码重新确认具体差距，并保持以下已有要求：

- UI、主进程、文档和能力声明一致；开放操作前检查新鲜能力、权限、对象关系和资源池范围。高级操作已有的界面及 IPC 保护继续保留。
- 凭据和可复用会话保留在主进程，错误与日志脱敏。
- 超时、断线或结果未知时不自动重放写请求；先核对原 Task 与实际资源状态。取消请求不等于操作已经取消，清理失败不覆盖主要结果。
- VM、模板、快照、磁盘、SR 与网络的删除分别校验归属；数据删除需明确选择，分离与销毁保持不同语义。
- 兼容性依据 Published XAPI 契约和运行时能力，测试声明保留环境与范围。单一服务器、mock 或构建结果不能代表通用兼容或正式发布。

内部观察包继续使用现有构建和内容审计流程。首个正式发布仍需原 B0–B8 各域完成条件、实机验收、签名/公证、安装与声明核对；本次整理不关闭工单或解除发布保护。
