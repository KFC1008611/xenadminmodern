# 桌面交互与批量任务行为

记录当前源码的桌面行为；日期标注对应功能变更，安装包与实机验收范围见 [验证记录](validation.md)。桌面布局覆盖 1024、1280、1440 和 1920 像素宽窗口，无移动端适配目标。

## 工作区简化（2026-11-10）

连接后直接进入虚拟机与模板列表。侧栏按资源池、主机展开，选中主机直接显示 CPU、内存、版本和身份信息，并可切换虚拟机、网络、存储、监控、补丁。主机标签进入 URL，切换主机保留标签，进入 VM 后返回恢复原主机清单与搜索。池和全部资源列表使用 44px 顶栏切换资源类型。断开连接从对应资源池的更多菜单操作。页面内移除重复的范围选择器、可见列表标题与常驻说明。侧栏移除品牌文字，列表数量和操作放在同一行，正文上下留白 12px。

主机 VM 标签按实际驻留主机、本地存储归属和首选主机展示，模板与未分配 VM 位于池列表。存储按 PBD 显示当前主机连接的 SR，未挂接状态保留。网络对象属于池，当前主机的接口和链路通过 PIF 显示，删除确认继续检查整个池的关联。新建 VM 默认选择当前主机，创建前仍需核对向导。身份变化清理旧标签内编辑状态，读取失败保留具体错误和重试。

选中资源池后从「池设置」查看常规、用户与权限、高可用。设置中的连接始终来自 URL，断线后保留原范围并禁止操作，重连代次变化后重新读取。工作区应用设置和外观位于侧栏底部。

任务通知通过「全部任务」打开操作、服务器与批量记录。记录页复用原组件，通知持续负责后台观察，避免页面新增重复轮询。多个取消入口共享提交保护。VM 列表的搜索、类型、多列排序进入 URL，从详情返回恢复原条件。

旧仪表盘、权限、池管理、批量任务及主机高可用链接保留跳转。监控采集与告警监听由应用启动，页面切换不中断，连接身份变化停止旧采集。具体布局和兼容路径见前端界面规范。

参考 XenAdmin/XenCenter 的对象上下文与标签页组织，以及 XO 的资源管理方式。安全边界、能力禁用、原任务跟踪和写后确认继续沿用现有工作流。[XenCenter 标签页](https://docs.xenserver.com/us/en/xencenter/current-release/intro-xencenterworkspace/tabs.html) · [XO 资源管理](https://docs.xen-orchestra.com/manage-your-infrastructure/manage_infrastructure) · [XAPI Task](https://xapi-project.github.io/xen-api/classes/task.html)

## 多列排序、任务历史、连接恢复与主机信息（2026-11-05）

连接报错区分地址解析、主机/网络不可达、系统拒绝联网、本机地址不可用、端口拒绝、超时、连接中断，以及证书和协议错误。共用 XAPI 错误归一化提供中文原因、处理建议和原错误码，不在正文回显原始套接字信息；原始信息保留在诊断详情并继续脱敏。macOS 对不可达或系统拒绝访问补充本地网络权限检查，不将其断言为根因。认证失败仍按 XAPI 明确返回处理，网络错误不要求更换密码；证书过期、信任链或名称问题不引导关闭验证。未知传输错误提供中文通用检查步骤，并保留诊断详情。连接、重连、凭据保护和资源操作重放规则沿用原行为。

虚拟机与模板列表默认名称升序。普通点击表头采用单列排序，Shift + 点击依次追加排序列；已选列再次 Shift + 点击只切换自己的方向。例如类型、名称均升序时，先按类型分组，再按自然名称排列。表头标出多列优先级和方向，刷新与筛选保留排序；缺失值在对应分组内置后，同值按连接及引用稳定排序，Shift 范围选择沿用最终可见顺序。

任务通知中，各类活动记录默认可见，已完成、明确失败和已取消的记录默认折叠于「已结束」。展开后可以删除本地记录；删除范围、持久化、取消和恢复日志保护沿用原契约。读取故障、原记录丢失及导出清理未完成的条目继续可见。折叠不影响轮询；独立服务器任务页仍展示完整列表。

手动断开关闭会话并保留本次运行的端点、连接 ID 和主进程凭据；侧栏展开、图标栏、资源读取异常详情均可重连，连接页也保留未保存的失败端点。各入口共用请求和忙碌状态。需要更换密码时在原服务器上重试，保存配置的密码仅在认证成功后更新，IPC 凭据脱敏覆盖位置参数。自动重连遇到明确认证拒绝时停止尝试；手动断开取消自动恢复，迟到登录响应不能恢复连接。重连只恢复会话，不重放资源写操作。

主机基本信息覆盖 CPU 数量、型号与插槽、内存总量/已用/可用、运行中 VM 数和版本；详情提供地址、主机名、UUID、CPU 频率和系统构建。主机监控也显示容量，百分比保留为利用率。内存使用 `host.query_data_source` 的 `memory_total_kib` 与 `memory_free_kib`，换算为字节后以二进制单位显示。读取故障、无效值和可用量超出总量分别保留原因；不使用已移除的 `host_metrics` 内存字段，不用零填充未知数据。没有新增依赖或用户配置。

依据：[XAPI 主机数据源](https://xapi-project.github.io/xen-api/classes/host.html#query_data_source)、[host_metrics 字段移除说明](https://xapi-project.github.io/xen-api/classes/host_metrics.html)、[XenAdmin 重连命令](https://github.com/xenserver/xenadmin/blob/master/XenAdmin/Commands/ReconnectHostCommand.cs)、[XO 会话恢复](https://github.com/vatesfr/xen-orchestra/blob/master/packages/xo-server/src/_xenServerAutoReconnect.mjs)与[XO 任务界面](https://github.com/vatesfr/xen-orchestra/blob/master/packages/xo-web/src/xo-app/tasks/index.js)。排序与折叠交互按本项目规范实现；参考资料不代替真实资源池验收。

## 外观与页面布局（2026-10-23）

界面遵循[前端界面规范](frontend-spec.md)，使用灰色底、紫色主要操作和统一状态色。工作区深浅色通过「设置 → 外观」切换，连接页顶部保留外观菜单；选择保存在本机，下次打开恢复。首次使用采用系统主题偏好。弹窗、图表、表格和任务面板同步切换，虚拟机控制台保留客户机原始画面颜色。

顶部在列表中显示范围和资源类型，在详情中显示面包屑，右侧保留刷新和任务通知。侧栏可折叠，选择全部资源或单个池，底部提供告警与设置。断开操作位于对应池的更多操作菜单。虚拟机列表行内保留启动、关闭或恢复快捷操作，其他操作收进对象的「更多操作」菜单；菜单显示禁用原因，危险动作仍须确认。表格在自身容器内横向滚动，避免长名称和操作列扩大整个窗口。

页面删除重复范围说明和空泛引导；虚拟机计数仅列出非零模板类别，资源读取正常时不显示常驻成功条。读取异常、旧数据时间、禁用原因及操作后果继续显示。禁用提示改用操作名称和「暂不可用」，内部审计编号及实现阶段不进入常规提示；所有原有能力保护保留。

## 术语与作用域

| 名称 | 含义 |
| --- | --- |
| 已保存服务器 | 用于稍后连接的端点和登录配置，保存不表示已经连接 |
| 管理连接 | 已认证的 XAPI 会话，确定操作的资源池范围 |
| 资源池 / 主机 | 资源池是管理边界，主机是其中的计算节点；单主机环境也属于一个资源池 |
| 活动资源池 / 统一资源视图 | 前者是当前操作的默认上下文，后者汇总多个池；汇总不改变资源归属 |
| VM / 模板 / 快照 | 可运行实例、创建 VM 的基准对象、某一时点的可恢复记录 |
| SR / VDI / VBD / PBD | 存储仓库、虚拟磁盘、VM 与磁盘的挂载关系、主机与仓库的接入关系 |
| Network / PIF / VIF | 二层网络、主机网络接口、VM 虚拟网卡；PIF 可以承担物理、Bond、VLAN 或 Tunnel 角色 |
| 迁移 / 复制 | 前者改变原对象的位置，后者创建副本并保留源对象；跨池操作必须明确源池与目标池 |
| 分离 / 销毁 | 分离解除接入或挂载关系并保留数据，销毁删除对象及其内容 |
| 资源池任务 / 批量任务 | 前者由 XAPI 跟踪，后者由应用编排多个 VM 的独立执行结果 |

对象名称和 OpaqueRef 都不能单独标识跨池资源。读取、关联、确认与提交必须保留资源池范围；连接重建后拒绝旧代次结果。VM 删除保护与 HA 重启策略是不同设置。

## 基础资源操作

| 资源 | 当前操作范围 |
| --- | --- |
| VM | 清单、详情、电源、名称与配置、模板创建、停机删除、同池主机迁移 |
| 虚拟磁盘 | 清单、创建、挂载、元数据、按能力扩容、单盘同池 SR 移动、独占停机磁盘删除 |
| 网络 | 普通 Network 创建、查询、重命名、无连接时删除；VIF 创建、连接、断开、删除和换网 |
| 存储接入 | 新建 NFS、iSCSI 和 NFS ISO 仓库；发现已有 iSCSI SR 后按 UUID 明确选择保留数据接入 |
| VM 快照 | 创建、查询、重命名、恢复、删除；独占 RW 磁盘清理失败时报告残留 |
| VM 模板 | 分类查询、克隆与设置、停机 VM 转换、向导或快速创建 VM；删除用户模板时默认保留磁盘，可明确选择同时清理所属硬盘 |

操作仍需满足 XAPI 当前能力和各入口保护条件。停机整机存储移动、跨池迁移，以及 SR/PBD 生命周期、Bond/VLAN/PIF/Tunnel 等高级变更继续受保护；批量迁移不在支持范围，具体能力以 [证据清单](../src/shared/evidence-manifest.ts) 为准。

同池 VM 迁移和单盘 SR 移动在 Task 成功、目标主机或 SR 核对通过后显示完成。删除 VM、模板或快照时区分对象、挂载关系与磁盘数据，不能把所有挂载磁盘认定为可删除的独占磁盘；清理失败需报告残留。

### 名称简介与内存

VM 名称与简介独立编辑，运行中也可修改；名称去除首尾空白且不能为空，简介可清空或多行。只提交变化字段，保存前检查并发修改，保存后读回核对；部分保存保留已生效字段。vCPU 在概览独立编辑，仅停机可调整。

内存页区分主机当前分配容量、动态范围和静态启动上限。指标不可用时继续显示配置；停机显示未运行，页面可见时每 10 秒刷新。GiB 输入允许小数，但提交必须转换为安全范围内的整数 byte，满足 `static_min ≤ dynamic_min ≤ dynamic_max ≤ static_max`，动态容量为正。

运行中只调整静态边界内的动态范围；修改启动上限要求停机，静态下限保留平台原值。固定模式令动态上下限相同，停机时修改固定容量会同步启动上限；已有配置未变化时保留原有启动余量。保存前按电源状态及 allowed/blocked operations 重新检查，不自动关闭或重启 VM。后台刷新保留正在编辑的草稿。

### 模板与 XVA

虚拟机与模板统一列表默认隐藏系统自带模板，可在类型筛选中勾选“系统模板”查看；创建向导中的系统模板照常可用。

删除用户模板时可勾选“同时删除所属硬盘”，默认保留硬盘。清理前逐盘读取 VBD/VDI，只接受 `other_config.owner` 为 `""`（XAPI provisioner 标记）或 `"true"` 的 Disk/RW 归属关系，并要求 VDI 只有该 VBD、不共享、不只读、不是快照且无当前操作。归属标记识别与 VM、快照共用；`owner=false` 或无标记不获得删除资格。读取失败时不开始删除。先由 XAPI 确认模板删除，再清理合格的 VDI；光驱介质不删除。受保护的盘和清理失败的盘会返回引用并保留在窗口中供存储检查，不能重复提交模板删除。刷新失败单独报告，不把已经完成的删除显示为删除失败。

对象、磁盘与挂载关系按 [XAPI 模板 provisioner](https://github.com/xapi-project/xen-api/blob/master/ocaml/xapi/xapi_templates.ml)、[XO 模板删除说明](https://docs.xen-orchestra.com/vm-templates)及 [XenAdmin/XenCenter 删除确认](https://github.com/xenserver/xenadmin/blob/master/XenAdmin/Dialogs/ConfirmVMDeleteDialog.cs)的语义区分：删除模板记录不能替代显式磁盘清理。

停机、无当前操作的普通 VM 可原地转换为用户模板并写入 `instant=true`；控制域、快照和 vApp 成员不进入此流程。用户模板的快速创建要求此标记，依次观察异步 clone、provision 和 start，在 provision 后分配名称，沿用模板计算、磁盘、网络和 provision 配置。无标记的用户模板可在菜单中单独启用。启动失败保留已经创建的 VM；写入结果未确认时持久保存原池任务和对象身份，再次操作只核对原尝试。具体条件、恢复限制和实机验收边界见[模板快速创建](vm-quick-create.md)。创建向导保留用户明确删除全部磁盘或网卡的选择；创建结果无法确认时保留对象引用，避免重复创建。

XVA 预览列出 VM/模板、磁盘与 VIF。导入选择目标 SR、每个源 VIF 的目标网络和可选 Home Server，默认保留归档中的名称、描述及 VM/模板身份。显示可用容量，受理和上传前检查主机 live/enabled、PBD、PIF 及存储/网络的共同可达性；归档大小和 VDI 虚拟容量不能直接代表实际分配。完整检查归档后再上传，完成前读回模板类型、Home Server、网卡映射及磁盘归属。需要把普通 VM 转为模板时，在导入后单独转换。

上传断网后不续传或自动重传。重连创建新本地连接 ID 时，后续重试按原资源池 UUID 找到当前已连接的原池，只核对原 Task。无法读取时保留静态原因，不持续显示上传动画；恢复本地记录不等同于应用重启。完整边界见 [XVA 传输](xva-transfers.md)。

重启后可直接取消已有导入/导出，取消入口自行加载记录；重连后按已保存的原池 UUID 找回当前连接。旧恢复记录没有原池 UUID 时禁止仅凭本地连接 ID 发送取消请求。导出在 Task 结束、清理尚未开始之间中断后，后续查询仍可恢复该次清理，避免永久显示“清理中”；清理完成后移除恢复时的待清理提示。导入完成后的 VM、Task 和模板刷新使用结果返回的当前原池连接。

导出按电源状态选择直接导出、正常关机后导出或 checkpoint；checkpoint 包含内存，可能短暂挂起并恢复 VM。HTTP 显式保留挂起状态及内存镜像，导入确认页说明保持挂起，完成前核对其状态、内存镜像 SR 和容量；恢复运行仍需兼容主机。受理后准备与传输均进入后台。传输先写临时文件，整个归档验证和 XAPI Task 均成功后排他发布到新文件名，避免并发或外部文件被覆盖；清理尝试结束后发布最终结果和结构化警告。

## 资源池与读取状态

资源池页面的断开操作以 URL 中的连接为目标，侧栏进入资源页时同步当前连接；全局页的顶栏断开操作使用当前连接。全局资源清单可汇总多个池，创建操作按页面的资源池选择或唯一连接确定目标，并在表单中显示。面包屑中的资源池链接进入该池的主机列表。

页面展示对应资源域的加载、读取失败和最近成功时间。读取失败时保留旧数据并注明其来源；连接已失效时提示该池不可操作。错误提示提供重新读取入口。主机维护状态随可见主机集合更新，不因维护状态自身刷新而循环请求。

批量选择保留跨池选择，展开已选清单可按资源池核对和移除。当前筛选外的选择会计数；有不可见选择时，提交前必须查看完整目标清单。

## 弹窗、表格与导出

主要自制弹窗采用 `DesktopDialog`，提供模态语义、焦点限制、Escape 关闭和关闭后返回触发控件。嵌套弹窗关闭后保留父弹窗。请求处理中关闭行为受 `busy` 控制。弹窗最高为窗口高度减 64 像素，长内容在内部滚动；已保存服务器列表的标题和关闭按钮保持可见。

VM、网络及批量任务表保留横向滚动，并固定右侧操作列。导出任务面板关闭后，可通过顶栏的导出任务按钮重新打开已有任务。

## 保存的服务器

XAPI 返回 `SESSION_AUTHENTICATION_FAILED` 后，连接页和已保存服务器窗口在原卡片展开密码输入，显示具体登录错误。用户输入新密码后仍连接原 profile；成功后由既有保存流程更新密码。无法读取保存密码时保留同一输入入口，网络或其他错误不推断为凭据失效。

渲染进程只获取是否保存密码的布尔值，连接保存配置时由主进程读取凭据。编辑密码输入框始终为空；留空提交 `null`，保留原密码，输入新密码才替换。启动自动连接失败在连接页展示。

## 批量任务

批量范围包含启动、正常关闭、正常重启、挂起、从挂起恢复、暂停、继续运行、创建快照和删除。工具栏按全部目标的状态及 XAPI 能力禁用不适用操作并指出具体 VM，执行前逐项重读身份和能力。所有提交先核对完整目标清单和操作后果；确认页冻结此次目标，条件变化时禁止确认。强制关闭和迁移继续逐台核对，IPC、任务管理器及历史重试拒绝批量执行；正常关闭和重启绝不自动升级为强制操作。

VM 列表支持 Ctrl／⌘ 点击增减选择，Shift 按当前排序选择可见 VM 范围，跳过模板且保留范围外选择；复选框、全选、筛选外选择核对及连接身份保护共用原目标集合。普通点击 VM 名称仍进入详情，提交期间锁定选择。

单台及批量 VM 删除默认勾选所属硬盘，可取消勾选保留数据。只删除已停止 VM 及其独占、可写、归属明确且没有在途操作的普通硬盘；共享盘、只读盘、快照盘和光驱介质保留。单台窗口逐盘显示选择及保护原因，批量窗口显示统一选项和保护范围。磁盘清单加载失败时禁止提交；单盘身份或关系读取失败时禁止删除该盘。VM 删除读回确认后再清理磁盘，清理前重读 VDI 身份和关系，逐盘读回确认删除。VM 已删除但磁盘清理失败时保留具体 VDI 引用，不计为完整成功；删除任务不提供直接重试，须重新读取 VM 与存储清单。单台窗口禁止重复删除，清单刷新失败单独展示。默认值为窗口行为，没有新增配置项。

操作语义参考 [XAPI VM](https://xapi-project.github.io/xen-api/classes/vm.html) 的 allowed_operations、pause、unpause、snapshot、destroy，以及 [XenCenter 删除 VM](https://docs.xenserver.com/en-us/xenserver/8/vms/delete.html) 的 VM、磁盘独立选择及不可恢复后果。默认勾选按本项目当前要求实现。

提交使用持久请求 ID，同一请求重复到达返回原任务；响应未确认时再次提交相同目标沿用该 ID。前端提交期间立即锁定；主进程也拒绝同一 VM 尚有未结束批量任务时再次排队，包括同池的不同管理连接。不同 VM 的任务可以并行，任务页保留全部活动任务，并为每个任务提供“停止后续操作”。右上角任务通知汇总全部活动任务及历史，并可跳转完整任务页。通知默认收起，新任务受理和任务结束不自动展开；最终结果、逐项错误在通知中保留，用户可删除已结束的本地记录。列表读取失败或后台历史清理不能使已收到的结果消失。

列表摘要不包含逐项结果。当前观察的任务进入终态后单独读取详情，包括受理响应返回前已结束的任务；详情读取失败时保留已收到的逐项错误并显示具体原因，重新读取成功后更新。摘要补充开始、结束时间不会清空相同结果；重试后的结果变化仍使旧详情失效，旧响应不能覆盖正在执行的新一轮任务。

预检查和实际操作共用默认最多 5 项的队列，逐项读取最新能力及 VM UUID、资源池 UUID、连接代次。慢目标不形成整批预检查屏障；已满足目标状态也必须先核对身份。此队列用于互相独立的 VM 运维，不编排应用依赖或保证组内启动/关闭顺序。

任务记录使用 `userData/state/batch-tasks.json` 检查点与 `batch-tasks.jsonl` 增量日志；首次启动兼容原来的数组历史。任务受理、项目开始及结果先写入并刷新日志，进度计数在内存中派生，不为每次推送重复保存全部历史。恢复仅忽略未写完的最后一条日志；完整损坏记录保留并报错，不继续派发。检查点含日志序号，检查点保存与日志清理之间退出也不重放请求。日志写入失败后停止新派发，保留已有记录，恢复存储并重新启动后核对未确认项目。

普通已结束或已取消且没有失败的任务保留最近 50 条；活动、明确失败或结果读取失败的任务不自动清理。检查点在无活动任务时按日志量或历史清理合并。提交请求去重随相应任务记录保留。

| 状态 | 含义 | 重试行为 |
| --- | --- | --- |
| 排队中、执行中 | 仍有待处理或执行中的项目 | 不能重试 |
| 正在取消 | 不再提交未开始项目，等待在途请求返回 | 不能重试，也不声称撤销已提交请求 |
| 已结束 | 各项均有确定终态，可包含明确失败 | 仅手动重试明确失败项 |
| 已取消 | 未开始项目已取消，在途请求已返回 | 仅明确失败项可手动重试 |
| 读取结果失败 | 响应丢失、服务器返回无效数据或应用退出时未读取到执行结果；保留具体错误，提示恢复连接后查看虚拟机状态和服务器任务记录 | 不自动重试，也不进入“重试明确失败项” |

进度中的“已处理”包括成功、明确失败、读取失败和未执行；成功数不包含后三者。批量界面不再展示“结果未确认”状态；历史和 IPC 中的 `unknown` 标记继续用于区分读取错误与服务器已确认的执行失败，防止重复提交关机、重启等写请求。历史详情保留每台 VM 的连接、状态和错误原因。提交已被接受而后续进度查询失败时，提示任务 ID 并只移除此次已提交的选择，保留用户之后的新选择。

历史重试先重新读取明确失败项，核对目标和服务影响后才提交。主进程比较确认的项目 ID、重试次数和请求 ID；失败集合变化时要求重新核对。成功、读取失败和未执行项目不重放；旧强制停止、删除、迁移及快照任务不可重试。缺少完整身份的旧记录仅供查看；连接变化后需从当前列表重新选择目标。

历史页读取重试项期间禁用本行删除；若记录从通知中被删除，迟到的读取响应不再弹出重试确认。提交期间两个入口均禁用删除。重试沿用原任务 ID，成功受理后清除其旧删除标记，保证新一轮最终结果继续在通知和历史页保留；提交失败不恢复旧记录，不影响其他任务的删除标记。

重新启动应用不会重放历史任务。遗留运行项显示“读取结果失败”及退出时未读取到服务器执行结果的原因，尚未开始项显示“未执行”，原成功和失败结果保留。窗口重新绑定使用同一任务管理器。

删除、快照和迁移沿用各自的单 VM 工作流与现有能力保护；批量范围收缩不放开受限功能。

## 能力说明

主机亲和性表示偏好主机，不宣称强制绑定。反亲和放置由服务器 VM Group 提供。服务器返回 `VM.groups` 时按组读取真实 `placement` 与成员；缺少此字段显示服务器未提供信息，读取失败显示错误，不把空数组当作已确认未配置。客户端目前只读查询，不把任意 VM 清单写入元数据伪装成放置策略。

## 验证边界

组件测试覆盖路由目标、隐藏选择确认、凭据边界、目标冻结、焦点、全部活动任务和失败重试确认。批量服务测试覆盖操作范围、持久请求去重、跨连接目标互斥、限流、取消与在途请求竞态、明确失败重试、旧历史兼容、日志中断恢复及保留策略。

## 基础模块补充行为（2026-10-20）

存储详情按资源池和 SR 身份选择，扫描后随最新清单更新；切换资源池不会保留另一池的详情。PBD 按资源池保存读取状态，ISO 按资源池和 SR 保存；断开、重连、池身份变化及晚到响应不会污染当前清单。VDI、PBD、ISO 和精简配置统计读取失败显示原因和重新读取入口，不把错误显示成空清单。存储卡片支持键盘选择，长名称在桌面宽度内截断或换行。

创建 SR 的向导显示目标资源池并允许选择该池主机，确认页再次列出目标。成功后关闭向导并定位新 SR。iSCSI 目标选择同时保留探测得到的地址、端口和 IQN；后续 LUN 探测及创建使用相同端点。可选端口为 1–65535 的整数，缺省 3260。PBD 接通和默认存储设置在原提交中读取实际状态；短暂读取失败自动恢复，连续失败则显示具体读取故障。

网络拓扑按池显示。VLAN 通过其未标记流量接口找到所属网络，缺少 PIF carrier 或 Tunnel active 信息时显示“未知”。承载 Tunnel 的物理网络仍按自身类型显示。Bond/VLAN/PIF 读取失败保留已知数据并说明错误，可重新读取；跨池及重连晚到响应被丢弃。

创建普通网络和重命名后读取网络记录核对名称。创建响应丢失、返回对象无法确认或创建后读取失败时，弹窗提示结果未确认并禁止在原表单重复提交。已获得创建引用时自动读取原对象，连续读取失败显示具体故障；丢失创建引用时不按同名对象认领结果。重命名只允许一个在途提交，断开连接后写操作不可提交。高级拓扑写保护保持原策略。

VM 详情、设备、快照和高级配置的本地状态属于一个资源池和 VM；切换目标重建视图，旧读取和删除事件之前的读取不能覆盖当前状态。网卡、磁盘、ISO、快照和高级配置读取失败有独立提示；基于陈旧状态的操作入口等待重新读取。模板选择读取失败可重试，切池不会回填旧模板。

VM 删除保护使用服务器的 `blocked_operations.destroy`。启用保护不改变 HA 始终运行；取消时仅移除本应用设置的原因，其他工具或管理员设置的保护需从原来源解除。删除服务先检查保护，避免先处理磁盘后才发现 VM 受保护。开关提交后读取配置核对结果。

旧版本通过保护开关写入的 `ha_always_run` 值不会被本次修复自动更改。已有环境需单独核对该 HA 配置，并按实际高可用策略处理。

离线 vCPU 调整同时确定启动数量和最大数量，按 XAPI 约束顺序写入并读回。部分应用时展示实际启动/最大数量，读回失败说明结果未确认，不自动再次写入。高级页的启动数量小于最大数量仅表示预留 vCPU 余量，不据此声称客户机支持在线热插拔。

操作已经完成、后续刷新失败时，反馈保留完成结果并提示重新读取，不再同时显示操作成功和失败。失败的进度卡片可以关闭；关闭不会重试操作。普通操作的完成记录保留至用户删除，不使用自动清理定时器。新的确认替换旧确认时，旧请求按取消结束。

上述行为是本地实现契约，真实服务器、原生文件选择及完整退出后的凭据恢复验收范围见 [验证记录](validation.md)。

## 常用操作流程补充（2026-10-20）

网络、存储与 VM 的关联跳转保留资源池及对象身份；侧栏会展开目标资源池，便于继续进入同池其他资源页。网络详情使用 `?network=<ref>`，存储详情使用 `?sr=<ref>`，VM 详情使用 `?tab=network` 或 `?tab=storage` 等有效标签。浏览器前进、后退恢复对应的对象与标签。

### 存储

统一存储页可选择新建存储的目标资源池；向导再次显示目标池和接入主机。NFS/iSCSI 表单使用中文标签；扫描失败或没有结果时，用户可以返回修改参数后重试。已有明确共享路径或目标信息的填写能力保留。创建成功后定位新仓库；较窄桌面把选中仓库详情放在清单前方，窗口宽度达到 1280 像素时与清单并排显示。

仓库详情按“虚拟磁盘”“主机接入”“ISO 镜像”“精简配置”组织。虚拟磁盘显示名称、容量和同池关联 VM；进入 VM 存储页可继续设备管理，VM 磁盘也可返回所属仓库。主机接入链接进入对应主机。未匹配的挂载关系及关联 VM 读取失败有说明与重新读取入口。

“编辑仓库信息”修改名称和描述；描述留空表示清除。主进程先读取当前信息，检查待修改字段是否被其他操作更改，只写需要变更的字段，再读回核对。写响应丢失后自动读取实际信息；已经符合目标值时正常完成。部分生效时更新实际基线并说明未完成字段，连续读失败时显示具体故障。仓库信息编辑不改变底层存储、已有磁盘或主机接入。

虚拟磁盘可在仓库详情中重命名。保存后读取实际名称；写响应丢失或短暂读失败时自动读取原磁盘名称，已生效就正常完成；连续读取失败后报告原因。扫描仓库、设置默认仓库和扫描 ISO 提供可见文字入口及完成/失败反馈；分离、销毁等既有保护保持不变。

### 网络

统一网络页提供资源池选择。创建弹窗说明目标池和内部网络用途，创建成功后定位新网络详情；明确失败保留输入供修正，未确认创建继续阻止重复提交。

点击网络名称可查看描述、类型、MTU、UUID、主机接口及接入的 VM。接口名称、角色、IP 与链路状态分别展示；缺少对象或读取失败不解释成没有接入。用户可进入关联主机或 VM 的网络设备页，并从 VM 网卡返回网络详情。

删除确认显示网络名称、资源池、主机接口与虚拟网卡接入数量及影响；取消不会发送删除请求，明确失败保留确认上下文。确认期间若最新清单出现接入设备，则不能提交。高级网络操作的保护及解禁条件不变。

### 虚拟机

创建向导支持返回已访问步骤，包括从确认页修改名称、安装介质、主机或设备配置；确认页显示目标池和需要补充的具体配置。切换目标主机时保留磁盘大小与网卡设备，只清除无法由该主机使用的资源选择并说明原因。vCPU 和内存同时参与主机可用性检查，磁盘大小使用 GiB。模板网卡映射未读取完成或失败时，先等待或重新读取，不能把临时默认网络作为已确认配置提交。

模板磁盘由主进程合并真实硬盘 VBD/VDI 与 provision XML，按设备号去重，真实盘优先；光驱不计入硬盘数。XML 中的 SR UUID 对应到实际仓库，空 SR 使用已确认的资源池默认存储，找不到时要求用户选择。自定义模板展示完整硬盘计划并完整复制到所选 SR，容量检查包含 XML 中尚未创建的盘；提交前模板计划发生变化会要求重读。系统模板允许编辑最终硬盘计划，已有盘可扩容或更换目标 SR，只读盘不可调整容量。确认页展示各盘设备号、容量、只读状态和目标仓库。GiB 输入统一四舍五入到整数字节，前端、IPC 和主进程均拒绝非安全整数容量。

完整向导在 clone/copy 后、provision 前清除副本的磁盘 XML，再按计划复用、迁移或新建硬盘，设备号冲突时明确失败。ISO 安装复用已有光驱并更换介质，必要时创建设备 0–3 内的光驱；最终保留一个安装光驱。HVM ISO/PXE 分别设置光驱/网络优先；PV eliloader 提供 HTTP/HTTPS、FTP、NFS 安装源输入，并写入安装仓库，ISO 使用 cdrom。HVM 的 PXE 能力不依赖安装源元数据；无安装方式元数据的 HVM 模板默认不使用介质，仍可选择 ISO/PXE；无安装方式的 PV 模板可选择不使用介质。PXE 和 URL 安装至少需要一张虚拟网卡。

模板网卡按设备号保留 MTU、QoS、锁定模式及允许的 IPv4/IPv6 地址，创建新 MAC；网络步骤和确认页显示继承策略。提交后发现策略变化时要求重读，不静默放宽。更改 CPU 数量时保留有效且整除的每插槽核数，否则先重置为 1。创建完成前核对最终磁盘数量、设备号、SR、容量、读写和启动标记，以及所选 ISO。明确失败仅清理本次新建且归属明确的盘（包括只读副本）；不删除源盘。写结果未知保留对象且不重放，启动失败保留已经创建完成的 VM。

创建成功后进入新 VM 详情。详情动作显示文字，概览显示资源池和可识别的主机名称，并提供设备管理入口。普通关闭、暂停、挂起先确认目标及服务影响；挂起后可以使用“从挂起恢复”，暂停后使用“继续运行”。这些操作仍受电源状态、XAPI 允许操作、服务器阻止项、锁定及在途状态约束。2026-10-22 的电源入口与可用性变更见文末补充。

虚拟网卡显示连接状态，删除确认列出设备号、MAC、网络及影响；明确区分删除虚拟网卡与删除网络。设备页的关联入口保留同池作用域，关闭确认不发送设备删除请求。

带进度卡片的操作以同一张卡片显示“执行中 / 已完成 / 失败”和完整目标名称，成功时不再额外叠加一条成功通知。全部进度统一收纳到右上角默认折叠的任务通知中，展开后内部滚动；操作完成后的列表刷新失败单独提示，不改报操作失败。

本节的实现与验证记录分别列出组件、协议、生产页面和 Electron 证据。受控 API 或 loopback XML-RPC 通过不代表真实资源池验收，也不代表已安装应用已更新。

## VM 操作可用性补充（2026-10-22）

VM 列表和详情在可见时每 5 秒、窗口重新聚焦时读取最新状态，事件通知继续即时更新。开机过程中服务器的在途操作结束后，按钮按最新能力恢复。读取失败保留上次数据，按钮说明需要刷新；离线和正在确认/执行也使用各自的禁用原因。

VM 详情顶部刷新会重读当前磁盘、快照或网卡标签；全局 VM 清单成功刷新也触发当前详情和设备重读。磁盘电源状态或 VBD 关系改变后重新读取设备状态，关机后可直接执行当前允许的分离、删除等操作，无需切换标签。设备读回按请求代次隔离，失败可通过原刷新入口恢复；刷新不卸载已有操作窗口。

批量选择随当前 VM 名称更新。连接断开、池身份或代次变化、VM 删除、替换或转换为模板后移除失效目标并提示重新选择；其他池的选择保留。已打开的确认清单不跟随改名或身份变化替换目标，改为禁用确认并要求重新核对。原任务提交期间继续冻结目标，主进程仍执行最终身份校验。全局 VM 筛选池失效后回退到全部，恢复连接不抢回筛选。

重启和强制关闭以每次提交前读取的 XAPI 能力检查替代原全局禁用。启动、正常关闭、重启、暂停/继续、挂起/恢复和强制关闭共用主进程检查，同一 VM 的本地电源请求不能重复并发提交。列表和详情在确认时携带 VM UUID、资源池 UUID 和连接代次；主进程拒绝确认后已变化的目标。批量任务持久保留这份身份，重试时仍按原对象核对。操作使用 Async Task，确认任务成功后再核对 VM UUID、连接代次和目标电源状态。重启请求客户机正常重启，不自动升级为强制重启；强制关闭确认明确提示断电及数据丢失风险。运行、暂停或挂起的 VM 仅在 XAPI 允许时可强制关闭；服务器另有在途操作时也以其允许能力为准。

单项电源响应丢失、任务无法读取、最终状态无法确认时保留原有结果保护。批量电源遇到这些读取错误时显示“读取结果失败”和具体故障，不将其计为成功或服务器已确认的执行失败，也不自动重放。批量电源操作及失败重试均先确认目标和后果；批量只提供正常关闭，暂停/挂起的 VM 不能隐式升级成强制停止。单 VM 的正常关闭和强制关闭仍分别检查能力。批量既有历史保留内部 unknown 标记，重试仍只针对支持操作的明确失败项。

运行中的 VM 可按正常关机或 checkpoint 能力进入导出，每种模式单独判断；服务器未允许直接 export 不再阻止进入准备流程。“导出快照”采用包含内存的 checkpoint，期间可能短暂挂起并恢复 VM。主进程重新检查所选模式。运行中的 VM 仍不能直接导出；停止/挂起后直接导出需要 export 能力。

导出弹窗在打开或切换目标时选择可用的默认模式。打开后，能力或电源状态刷新保留所选模式和保存位置；所选模式不再可用时禁用“开始导出”并说明原因，用户可主动改选或等待能力恢复。快照导出不会因刷新自动变为关机后导出。

删除、转换模板、离线 vCPU 和静态内存上限继续要求停机；动态内存范围按现有在线能力判断。本轮本地验证不代表真实 XCP-ng/XenServer、RBAC 版本矩阵或跨重启单项操作恢复已经验收，范围见 [验证记录](validation.md)。

## 异步读取与操作结果确认（2026-10-22）

- 附加已有磁盘只接纳当前弹窗、VM 和连接生命周期的列表结果；旧响应不会更换已选磁盘。读取失败可以显式重读，附加完成后的列表刷新失败单独提示。
- VM 模板按资源池独立维护读取状态。暂时失败保留同一连接的上次数据并持续标注；失败池的模板菜单不可操作，重读恢复后可用。重连和较旧请求不会把旧模板带回当前清单。
- 主机网络接口在展开、重新展开、成功刷新主机/网络、显式重读和重连时重新读取。临时读取失败保留上次数据并显示错误。接口表格在卡片内部横向滚动，不撑开整页。
- 网络详情中的主机接口同样跟随当前池主机、网络清单的成功刷新重读 IP 和链路状态，保留连接作用域与请求代次保护。
- 磁盘激活、停用、分离和删除共用同步在途保护；确认等待、写入和回读期间禁用冲突按钮，取消或完成后释放。读取错误保持原地可重读，不能用旧设备状态继续操作。
- XVA 未提交确认页可返回修改存储和网络映射，保留文件与草稿；提交受理前停止草稿编辑；已受理的操作独立跟踪，可关闭弹窗或新建草稿，旧记录继续观察。切池或连接代次变化后重新选择目标资源。
- “取消任务”先显示正在取消，继续观察服务器状态。只有 `cancelled` 才显示已取消；`success` 表示正常完成、取消未阻止任务；`failure` 显示失败。主进程在原取消请求内等到任务终态，短暂读失败自动恢复，并通过 IPC 直接返回真实终态与结果消息。后续清单刷新失败或任务清理不覆盖已知结果。连续读失败、任务消失、超时或连接变化报告具体故障，无额外手动核对入口。
- 磁盘扩容被 XAPI 明确拒绝或提交前校验失败时，直接显示扩容失败及原始原因，不启动结果轮询。已受理或提交响应丢失时，在原操作中串行读取 Task 和实际容量。短暂读取失败后自动继续读取，保留已知 Task 成功事实。连续 3 次失败或等待 10 分钟仍无终态时报告具体故障；不重发扩容。实际容量达到目标且磁盘 UUID 匹配后正常完成，显示实际容量，无需手动核对。扩容成功后的父列表刷新失败单独提示。磁盘列表刷新保留操作弹窗，避免附加完成后弹窗重开或扩容完成状态丢失。

这些行为由 `tests/components/` 与 `tests/unit/` 中的受管回归覆盖；缺陷复现通过和修复后验证通过需分别理解。

## 操作结果与界面精简补充（2026-10-22）

用户操作在同一次流程中取得结果。通用 XAPI Task 每秒串行读取，连续 3 次读取失败或 10 分钟超时后报告具体原因；失败和取消以服务器终态为准。电源、磁盘移动、主机疏散、VM 迁移及存储/网络配置的结果读取自动恢复短暂故障；资源读回最多 3 次、间隔 500 毫秒。只重试读取，写请求不重放。连接或对象身份变化时拒绝接纳旧结果。

删除保护和 vCPU 保存的响应丢失后，自动读取实际配置；新建磁盘连接的响应丢失后，自动查找与原 VDI、VM、设备号匹配的 VBD。短暂读取失败或首次尚未出现的连接在原流程内恢复；已生效时正常完成，不能重复创建磁盘或连接。持续故障说明已创建的磁盘和具体读取错误。

VM 名称、简介和内存配置已经生效时正常结束保存。虚拟磁盘和存储仓库信息的写响应丢失后自动读取原对象。磁盘移动完成后的父清单刷新错误只提示刷新失败。扩容结果显示扩容前容量及读回的实际容量；完成卡片提供唯一成功反馈。

导入和导出进度串行读取，避免慢请求重叠。导出每轮进度读取完成后等待 1 秒再开始下一轮，进度更新、面板展开收起和通知刷新不重启轮询；未知结果退避到 10 秒继续读取，清理尝试结束且到达终态后停止。短暂 IPC 读取故障自动恢复，连续失败时报告具体原因；资源池 Task 等待有 10 分钟上限。连接恢复后按原池和对象身份核对原操作，不重传文件。HTTP 连接建立或传输连续 10 分钟无活动时关闭本次连接，再核对原 Task；正常持续传输不受短总时长限制。结果读取故障不要求用户声明“已经核对”才能关闭，关闭保留原导入记录。

XVA 校验、上传、下载分别显示本阶段的实际字节进度、数据量、已用时间和平均速度。下载总长度未知时只显示已接收量与速度，不用估计容量生成百分比；服务器处理显示原 Task 进度，准备、配置与清理使用不定进度。完整规则见 [XVA 传输](xva-transfers.md)。复制和磁盘扩容的进度来自服务器 Task，缺少字节计数时不推算传输速度；批量操作以实际已处理项目数反馈进度。同步扫描、创建和配置只有开始/结束信号时显示执行中，不生成虚假百分比。通用操作卡片在获得数值进度时同时显示百分比文字。

删除页面标题下的重复介绍、空态重复指令、功能宣传、内部实现说明以及重复对象摘要。保留实际结果、错误原因、风险、资源池/对象身份、字段约束和无障碍描述。桌面检查覆盖 1024×720、1280×800、1440×900。

## 真实连接与后台刷新补充（2026-10-22）

2026-10-23 精简界面后，资源状态摘要仅在首次读取和异常时出现，正常状态不占正文行。后台刷新继续显示最近成功数据，异常详情点击展开，在有界区域内滚动，保留旧数据时间和重新读取入口。一次 VM 事件只重读 VM；页面、事件和全局刷新合并同池同类的在途读取，清单顺序不随请求完成先后变化。模板通过独立版本更新。

写操作完成后的刷新会使该资源池、该类资源的旧读取失效，等待旧请求结束后串行读取新清单；多个完成通知可以合并补读。旧响应不会更新清单或最近成功时间，补读失败保留原数据并显示错误。此约定覆盖网络、VM、存储、主机、导入及批量操作的刷新入口。

单个请求的传输中断先查询原会话是否仍然可用；原会话有效时保留连接和连接代次。确认会话失效或独立健康查询也失败后才恢复连接，写操作不自动重放。最后一个连接短暂恢复期间保留当前页面、弹窗和草稿，相关操作按连接状态禁用；主动移除最后一个连接才返回连接入口。

XML-RPC 登录、get_* 查询、event.from 长轮询以及 Task/Async 请求使用 45 秒无数据超时；同步复制、克隆、创建、配置、扫描与 SR.probe 等其余同步操作不设客户端无数据截止时间，等待服务器返回结果。传输错误或主动断开仍结束请求，写请求不自动重放。空闲连接最多保留 30 秒，并允许按服务器 Keep-Alive 提示提前释放。每次调用使用独立请求选项，复用时重置 socket 超时，长操作与并发查询互不改变等待策略。

SR 容量 -1 表示未知，仓库继续可见。未知容量不按零计算，创建磁盘和扩容需要已知可用空间。资源池磁盘容量统计不包含 ISO 和内部 udev 仓库。资源未成功读取时显示暂不可用；保留的旧数据标注上次读取，资源读取失败不标为健康。主机监控按池显示实际采集错误，采集失败时说明具体原因。完整 RRD 归档超出读取上限时，按服务器时钟通过 rrd_updates 获取最近 10 分钟的 5 秒采样；同次采集后续使用该窗口，避免重复下载大归档。按主机 UUID 接纳样本，保留既有历史和响应上限。

2026-10-22 已更新本机应用，并完成两个现有资源池的只读验收：ISO 容量与存储清单正常，45 次采样中路由、标题位置和连接代次保持稳定，两台主机性能样本持续更新且采集错误为空。此范围不包含服务器写操作、版本与 RBAC 矩阵或长期运行验收，详见 [验证记录](validation.md)。

## 启动与虚拟机页面补充（2026-10-22）

查看已保存服务器只检查本地密码密文条目，不读取系统钥匙串。实际连接或保存密码使用异步系统加密接口；启动先显示连接页，各服务器独立自动连接。保存凭据无法读取时，原流程显示密码输入入口。macOS 更新后是否重新要求钥匙串授权受应用签名和系统授权控制；当前 ad-hoc 签名不能保证不同构建共用授权。

主机监控显示完整采集和增量采集的故障，成功恢复只清除对应故障，另一条采集流程成功不掩盖仍存在的错误。启动采集失败保留具体原因与重新读取入口。采集由应用启动，停止后到达的旧结果不回填状态。

VM 指标归档、增量及按需采集以批量写入本地历史；达到 10 万条上限时，每批只进行一次保留范围维护，避免逐点重建整张索引。保留时间、条数上限、去重和资源池隔离规则继续生效。

VM 列表显示运行/暂停 VM 的 Guest Tools IPv4 和 IPv6，按 IP 去重并支持搜索。无地址显示“未上报”，读取故障显示“读取失败”；关闭、挂起及模板行不展示旧地址。IP 按资源池批量读取，故障不影响 VM 清单展示。

VM 普通变更事件到达时，直接更新完整对象快照，同一 Guest Metrics 对象保留最近读取的地址；更换 Guest Metrics 对象或关机时清除旧地址。缺少对象快照、快照缺少列表必需字段，或运行/暂停 VM 缺少对应 Guest Metrics 地址时，合并调度一次 VM 清单读回。普通完整快照和删除事件不额外触发清单读取，既有周期刷新和操作后的明确读回继续生效。

详情页常用栏按当前电源状态展示主要电源动作，保留控制台与快照；“更多操作”提供电源、管理及危险操作三个分组。全部原有动作和禁用原因可查看。强制关闭和删除仍先确认，菜单支持键盘、Escape、点击外部关闭及确认取消后的焦点恢复，长菜单在桌面窗口内部滚动。

## VM 与模板复制补充（2026-10-23）

跨池复制前检查源当前光驱，已挂载 ISO 时提示具体设备，要求用户手动弹出后重读预检；空光驱和同池复制沿用原能力。提交前再次检查，结果核对也覆盖当前及历史光驱的介质关系。预检没有允许的方式时只显示阻止原因和重读入口，不显示其他复制分支的选择控件。

已停止的 VM 和模板使用统一复制窗口。同池可选择快速克隆或完整复制；跨池复制明确选择目标主机、传输网络，以及当前/历史磁盘、历史网卡和挂起镜像的目标。历史映射用于传输，跨池副本不保留 VM 快照历史，源对象及其快照保留。复制通过独立持久任务在后台观察，正常传输不受通用十分钟 Task 等待上限影响。目标管理连接断开时仍可读取源 Task 和请求取消；成功后保留副本引用，等待原目标池恢复核对。取消以服务器终态为准；重启和重连不重发复制，确定未发出请求的遗留记录结束为失败，允许用户重新发起。完成后可定位副本，模板只刷新目标池。规范、能力边界和官方对照见 [复制规范](vm-copy.md)。跨池迁移和停机存储移动仍受原有执行保护。

## 指标采集与大列表性能（2026-10-23）

默认每 30 秒发现新主机、运行中的 VM，并重试未成功的历史初始化。主机和 VM 的 RRD 归档成功初始化后，通过每 10 秒的 `/rrd_updates` 取得后续样本；后台 VM 历史初始化在同一连接同时最多 5 个请求，慢请求不会叠加出新一轮。停止或重启采集时中止旧 RRD HTTP 请求，未发出的批次不再启动，旧代次结果不写入历史。VM 内存比例使用同次 `VM.get_all_records` 返回的内存上限，不逐台读取记录；每轮增量重新获取元数据，配置改变后可更新分母。

指标快照采用单个异步写入器，每 256 条分片序列化并写入临时文件，完成后原子替换。并发保存请求合并，保存期间的新样本或重复时间戳更新会继续保存下一版本；退出前等待最新版本完成。失败保留原文件和内存数据并向调用者报告，后续保存可重试。告警和操作账本沿用各自原有的保存规则。

指标达到容量上限后，逐条按时间淘汰最旧样本，避免每台 VM 写入都重新排序完整缓存；主机和 VM 各十万条硬上限、按资源池隔离及重复时间戳替换规则不变。启动恢复由工作线程读取并解析指标文件，每 256 条分批建立索引，首窗可以先打开。指标查询、采集和告警计算等待完整恢复，失败保留原文件并向读取方报告；退出等待恢复与最新版本保存。

VM 详情在当前连接身份和采集代次内成功读取归档后复用已有历史与后台增量采集；直接打开详情时按需启动原连接的既有采集器。仅有旧样本不能跳过归档初始化，停机 VM 即使不在后台运行清单中，仍按需补齐应用关闭期间缺失的历史。补读失败或归档为空时，下次查询继续重试。同一 VM 的按需归档与后台初始化共用在途请求，连接替换和采集停止后不接收旧结果，重新连接或重启采集后重新初始化。详情自动刷新在每轮完成后等待 30 秒，手动刷新及时间范围切换合并执行；读取失败保留已有数据和具体原因。归档与增量语义见 [XAPI 指标文档](https://xapi-project.github.io/xen-api/metrics.html)，补充性能对照见[实施记录](reviews/2026-10-23-performance-followup/implementation.md)。

运行中或运行状态未知的 VM，成功读取归档后有 30 秒的缓存复用期；该 VM 的增量样本时间推进后重新计时，使用本地观察时间避免服务器时钟偏差影响判断。主机归档失败而没有增量游标、增量请求失败、增量持续返回旧时间或只更新其他 VM，都不能无限延长缓存复用；期限结束后，下一次详情查询重新读归档。最近 60 秒的批量运行清单确认 VM 不在运行时继续复用其历史，清单过期后按状态未知处理。复用已有批量元数据读取，不增加逐 VM 状态查询；归档补读不会清除仍存在的主机或增量采集错误。

虚拟机与模板列表自 2026-11-04 起取消分页，一页展示全部筛选结果。点击类型、名称、状态、IP 地址、资源池、主机、vCPU、内存表头可切换升降序，默认名称升序；数值列按原始数值，文本采用自然顺序，空值及读取失败置后。刷新与筛选保留排序，全选仍覆盖完整筛选 VM。VM 和模板以连接及对象引用合并，provision 类型转换更新模板缓存，旧模板记录不能重复显示已有 VM；同名对象分别保留。详见[前端界面规范](frontend-spec.md)及[快速创建列表一致性](vm-quick-create.md#列表一致性2026-11-04)。

任务、存储等无关数据更新不重建 VM 表格；连接状态检查未移除连接时保留资源数组引用。历史性能对照与验证边界见 [实施记录](reviews/2026-10-23-performance/implementation.md)；其中分页后的渲染耗时不适用于当前全量列表，大清单会创建更多 DOM 行。

## 逐页入口与反馈修正（2026-10-23）

侧栏选择全部资源或单个池，顶栏内切换虚拟机、主机、存储、网络。折叠侧栏保留可访问名称；多池汇总下创建和导入先选择单个池。详情链接支持键盘访问，面包屑截断项可查看完整名称。

资源池选择框不会随长名称扩大正文。资源池管理所选连接失效后自动选择仍连接的活动池或首个连接；没有连接时显示连接空态，不展示失效池的操作区域。未开放的主机、资源池、存储与 RBAC 操作继续禁用并说明原因。

## 基础管理结果核对（2026-10-25）

添加虚拟网卡时使用持久请求 ID，在服务器 `VIF.other_config` 写入本次请求标记。记录绑定资源池 UUID 与 VM UUID，提交前落盘；同一请求再次到达时返回原回执，有待核对记录时只读取原网卡，不重复创建。创建响应丢失后按请求标记、VM、网络和设备号定位；不按名称认领对象。热插拔响应丢失后读取实际连接状态；读取故障保留创建记录，表单提供重新读取入口并冻结原参数。恢复连接后可继续核对；明确创建完成后允许新建另一张网卡。

确认删除网卡时，同步结束原资源池、原 VIF 对应的创建记录，保留已消费请求 ID 的“已删除”标记；再次到达的旧请求返回网卡已删除，不创建替代对象。用户明确发起的新请求可以继续添加。对于其他工具删除的已知 VIF，仅在原池身份仍匹配且 `VIF.get_record` 明确返回 `HANDLE_INVALID` 后释放旧限制；权限、网络、身份变化及不含原引用的空清单均不证明删除。较晚的创建回执不能覆盖已删除标记。

导入向导在已结束后重新打开时启动新草稿，历史保留原结果，移除记录同步释放当前引用。导入/导出本地操作已不存在时停止自动读取并允许仅移除本地卡片；不将其声明为服务器执行失败，也不调用服务器取消或删除接口。原 Task 已确认的终态不能被取消回复或旧进度回退。完整生命周期和旧存储兼容规则见 [XVA 传输](xva-transfers.md)。

网卡列表提供“更换网卡网络”，确认可能的网络中断后调用 `VIF.move`，保留网卡 UUID、MAC 和 VM 归属。运行中 VM 的目标物理网络必须接入当前主机；完成前读回身份和目标网络。服务器不支持接口或权限不足时直接展示服务器错误，不通过删除重建模拟换网。

删除虚拟磁盘时，删除响应丢失后只读原 VDI，只有服务器明确返回 `HANDLE_INVALID` 才确认删除；断线、权限错误或无效记录不证明磁盘仍保留。无法读取时报告具体读取故障，不返回磁盘保留的错误结论，也不重发删除。光驱弹出响应丢失后读取原 VBD，确认空光驱后完成，不重复弹出。统一反馈显示具体状态读取故障，内部恢复标记不转换为操作成功或明确执行失败。

亲和主机配置按资源池和 VM 归属读取；切换目标时清空旧表单，旧请求不能覆盖新目标。配置或主机清单读取失败时禁止保存并提供重新读取，保存前重新检查对象，保存后读回主机与 VM 身份。亲和主机是放置偏好，不是强制绑定。

新建存储仓库增加 NFS ISO 库，使用 `iso` 驱动、`iso` 内容类型及 NFS `location`，接通目标主机的 PBD 并扫描后返回。iSCSI 探测发现已有 SR 时不创建或格式化 LUN；确认页列出 UUID，用户明确选择“接入已有存储（保留数据）”。提交时重新探测同一设备核对 UUID，使用原 SR 或注册原 UUID，再创建或复用目标主机 PBD。完成前核对 SR UUID、类型、PBD 归属和连接状态。未选择已有 UUID 不能覆盖创建；本流程不开放任意 SR 注册、分离或销毁接口。

Bond/VLAN/Tunnel、主机接口 IP 配置、SR/PBD 破坏性生命周期、Local EXT/HBA 创建、整机存储移动及跨池迁移的原保护继续保留。上述流程的本地回归不能替代真实资源池、存储后端、网络中断和打包应用验收。

## 模板设置与告警表单（2026-11-02）

模板设置先读取原池、原模板 UUID 和当前配置，校验模板类型、关机状态、在途操作及完整目标 CPU/内存约束，再开始任何字段写入。降低 CPU 最大值至当前启动数以下时，先降低启动数；增加时先调整最大数。只修改提交的字段，未提供的内存边界取服务器当前值。

每次写请求只提交一次，响应丢失时只读取该字段，确认已生效才继续后续字段。最后按原模板身份读回全部变更；短暂读取失败在原流程内恢复。明确的部分应用返回未完成字段和实际 CPU 配置，持续读取故障返回具体原因，不声明保存成功。窗口保留这些结果并冻结旧表单提交，用户关闭、重新读取模板列表后再编辑。保存成功后的清单刷新失败单独提示，不回退为保存失败。保存期间禁止修改字段、关闭窗口和重复提交；切换目标后忽略原异步结果。

字段写入之间连接身份变化时停止后续写入，统一返回 `RESOURCE_RESULT_READ_FAILED`；该代码经 IPC 保留，使尚未收到连接状态更新的窗口也能冻结旧表单，要求重新读取模板后再编辑。

告警阈值的精度与 IPC/服务校验一致，不使用输入步长额外限制取值；CPU/内存为 0–100%，其他指标为非负有限数，持续时间为 1–1440 分钟整数。保存期间冻结草稿及取消入口，重复表单提交合并为一次请求。没有新增配置项。

## 磁盘弹窗后续检查（2026-11-02）

新建和移动磁盘只提供磁盘仓库，排除 `iso`、`udev` 和 ISO 内容库，移动时排除当前仓库。清单读取失败可在原窗口重新读取；新建草稿在重读后保留，同一磁盘的新记录也不清空移动目标。容量暂不可用时不显示为零可用容量。最终仓库和磁盘操作校验继续由既有服务及 XAPI 执行。

窗口按连接、VM 或磁盘身份创建独立状态，关闭后重开恢复默认。清单与写请求均绑定原连接代次，迟到响应不能污染其他对象；同一渲染内的重复点击也只发送一次请求。提交后连接变化时停止旧窗口反馈，显示具体的结果读取故障并要求重新读取原磁盘及存储清单，不自动重发。移动请求出错后同样冻结原提交；窗口仍可关闭。

创建服务确认成功后独立等待父列表刷新，同步抛错和异步拒绝均作为列表刷新错误展示。`VDI_CREATED_ATTACH_INCOMPLETE` 保留已创建磁盘的事实及引用，分别展示明确的附加未完成或附加结果读取失败，刷新故障不覆盖原结果。上述改动不新增接口、传输恢复机制或配置项。

## 统一任务通知（2026-11-04）

连接页和工作区共用右上角任务入口，集中显示普通操作、批量任务、XVA 导入/导出、复制与服务器 Task 的进度、原因和最终结果。默认折叠，提交和任务结束均不自动打开；折叠、外观切换及切换页面不停止观察。服务器任务页与通知共用取消状态及同步提交保护，避免两个入口重复取消。取消请求后仍观察原任务，以实际终态显示完成、失败或已取消；批量仅停止后续派发，不撤销已开始操作。同步操作和不可中断阶段保留原因，不能伪造取消。

已结束记录可以删除。导入/导出按现有本地记录移除；复制、批量和服务器 Task 只持久保存本地删除标记，不调用 `task.destroy`，不删除资源或恢复、防重放日志。活动任务、读取状态仍在恢复的复制/XVA 操作及清理未完成的导出保留跟踪；本地记录明确不存在的 XVA 卡片仍可移除。普通操作完成记录保留至用户删除。原独立面板的展开偏好不再生效；没有新增操作接口或用户配置。界面、键盘、窗口尺寸和存储行为见[前端规范](frontend-spec.md#统一任务通知2026-11-04)。

取消与删除的语义沿用 [XAPI Task](https://xapi-project.github.io/xen-api/classes/task.html)、[XO Task API](https://github.com/vatesfr/xen-orchestra/blob/master/packages/xo-server/src/api/task.mjs) 及 [XenAdmin 后台 Action](https://github.com/xenserver/xenadmin/tree/master/XenModel/Actions)：取消请求不等于已取消，删除显示记录不应中断服务器任务。

## 内置软件更新（2026-11-09）

连接页和工作区右上角均提供「设置」，进入 `/settings` 页面中的「软件更新」区域。未连接服务器时可点击「返回连接」回到连接页，已有工作区时沿用侧栏和顶栏，面包屑显示「设置」。主进程使用 electron-updater 查询固定 GitHub 仓库的正式版本，启动延迟 15 秒且每 6 小时检查，禁止预发布与降级。用户可关闭自动检查并持久保存，手动检查继续可用；关闭设置不取消用户已开始的下载，在途自动检查结果不再回填。

设置页面使用单列布局，版本和当前操作同一行，自动检查开关独立分隔行，不常驻检查频率、保存成功和检查时间；故障、进度及安装后果按需显示。发现更新后设置入口显示「有更新」，进入设置点击「下载更新」在应用内下载并显示进度。离开设置不停止下载，重进设置读取主进程实际进度。下载完整性校验失败时必须重新检查，校验完成才显示「重启并安装」。普通退出不自动安装，重启安装必须点击按钮确认，先提示保存编辑内容。进程内已下载状态不跨重启伪造恢复，下次重新检查后由更新器核验缓存。

主进程在安装前阻止活动 IPC 请求、未结束的批量、复制及导入导出，安装准备期间拒绝新的管理请求。macOS 先经原生更新器准备并验证签名，再执行已有的任务、控制台、采集、连接与存储退出清理，最后交给平台更新器安装重启。清理失败禁止安装并要求重启应用。开发运行和 Linux 非 AppImage 包禁用更新。

GitHub Release 必须同时包含平台安装包和由 electron-builder 生成的更新清单。macOS 使用已签名、公证的 universal zip/dmg，Windows 使用签名 NSIS，Linux 使用 x64 AppImage。构建工作流先创建草稿，发布者核对后发布为正式版本。构建配置、更新能力实现和真实跨版本安装的验收分别记录。
