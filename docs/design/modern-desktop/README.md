# XenAdmin Modern 桌面界面样机

设计提案日期：2026-10-23。入口为同目录的 `index.html`，可直接用浏览器打开，无需安装依赖或运行构建。样机不接入 XAPI，所有资源、指标、日志和操作结果均为演示数据；应用标题栏明确标注这一点。

## 设计范围

覆盖总览、资源池、主机、虚拟机、存储、网络、任务中心、告警消息、用户与权限、设置十个页面。虚拟机详情包含概览、性能、控制台、磁盘、网络、快照、配置七个标签。

采用暖灰浅色和石墨深色，紫色用于选中状态与主要操作；绿色、琥珀色、红色用于成功、注意和错误。字体使用系统字体，图标取自项目已有的 Lucide 包并内嵌为 SVG。单文件中包含全部样式、图标和脚本，不加载外部资源。

桌面结构为标题栏、侧边导航、上下文栏、内容区、底部状态栏。资源池范围在导航顶部统一选择，具体对象通过详情页或抽屉展开。主要列表保留搜索、筛选、批量选择、状态文字和容量单位。长列表在内容区滚动，底部任务入口持续可见。

响应式目标为 1024、1280、1440、1920 像素宽的桌面窗口。较窄窗口减少次要表格列，总览的主机摘要收起；完整主机页面继续保留。较矮窗口收紧侧栏间距，导航和深浅色切换保持可见。最小画布宽度为 860 像素，不包含移动端方案。以上四组桌面尺寸已完成浏览器检查。

## 可以体验的交互

- 侧栏与设置页均可切换深浅色，外观及表格密度保存在当前浏览器本地。
- 资源池范围切换、虚拟机搜索和状态筛选、保留筛选外选择的批量清单。
- 虚拟机详情七个标签、正常关机或启动确认、模拟快照、名称和计算资源编辑。
- 三步创建虚拟机：基本信息、资源配置、确认；完成后向演示列表加入一台已关机的虚拟机。
- `Command + K` / `Control + K` 打开资源搜索；回车进入第一个结果。
- 存储、网络和主机详情，任务抽屉、模拟导出取消、告警已读操作。
- 添加连接、存储配置、内部网络创建、XVA 文件选择等表单预览。

控制台为静态终端预览。XVA 文件选择仅展示文件名和大小，不读取或上传文件内容。复制、迁移、导出、设备配置等弹窗用于评审布局，不表示已经实现完整配置或服务器操作。

## 与现有应用的关系

这是独立 HTML 设计提案，其演示数据与脚本不进入正式应用。用户确认设计后，React 前端按[前端界面规范](../../frontend-spec.md)迁移，主题切换按后续要求统一放到顶部「外观」下拉菜单。实际页面的验证入口和结果见[落地验证记录](implementation/README.md)。原 HTML 保留为设计参考，仍使用最初的侧栏外观控件。

对象划分及操作入口以项目现有的[桌面工作流](../../desktop-workflows.md)、[复制流程](../../vm-copy.md)、[XVA 传输说明](../../xva-transfers.md)为基线。尤其保留资源池上下文、对象关联跳转、操作确认、后台任务入口和完整批量目标清单；真实应用中的读取错误、结果未确认、权限与能力保护仍按既有契约执行。

## 本地检查

使用 JSDOM 执行页面脚本，检查了十个页面在两种主题下的渲染、七个虚拟机详情标签、搜索与筛选、筛选外选择、状态确认、创建向导、资源搜索、抽屉、任务取消、网络创建、消息已读及偏好保存。首轮 880 个断言通过，无脚本运行错误；此检查不验证像素布局或原生 `dialog` 的焦点行为。

另对两套主题的正文、次要文字、辅助文字、状态标签、选中标签进行 26 组文字与背景对比度计算，最低 4.62:1。没有把边框、图标或图表颜色当成文字对比度测试。

2026-10-23 经用户授权后，在内置浏览器检查了 1024×768、1280×800、1440×900、1920×1080 四组视口，共 32 组页面布局记录，均无文档或内容区横向溢出，侧栏与外观切换均可见。另走通了研发池三步创建、模板选择、新对象详情跳转、键盘搜索、任务抽屉、Escape 关闭和焦点返回；修正了模板单选框挤压文字及步骤切换后的焦点。浏览器未记录脚本控制台错误。

布局及交互检查记录见 [browser-validation.json](previews/browser-validation.json)。1440×900 的虚拟机页面截图：[浅色](previews/virtual-machines-light.jpg)、[深色](previews/virtual-machines-dark.jpg)。这些检查只覆盖样机及上述桌面尺寸，不代表现有 Electron 应用或真实资源池验收。

本机预览服务只提供本目录，绑定 `127.0.0.1`，不会连接资源池。HTML 也可以直接离线打开。
